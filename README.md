# Job search kit (шаблон)

Система поиска работы на Claude Code: поиск по 100+ сайтам вакансий, оценка каждой вакансии (навыки + совместимость с графиком),
CV под направления и под лучшие вакансии, трекер с кнопками «Искать», «CV», «Сообщение», «Подался» и ежедневная проверка почты.

Пайплайн поиска: сбор и предварительный отсев — Haiku (low), финальная оценка и CV — Sonnet (medium), надзор — основная сессия.
Подробно — `SEARCH.md`.

## Как начать
1. Нажмите **Use this template → Create a new repository** (лучше приватный: там будут ваши CV и отклики).
2. Откройте сессию Claude Code (claude.ai/code) с новым репозиторием. Для проверки почты подключите Gmail в коннекторах claude.ai.
3. Напишите: **«Настрой поиск работы по SETUP.md»**. Claude проведёт интервью, заполнит профиль, соберёт CV, опубликует ваш трекер
   и создаст запланированные задачи на вашем аккаунте. Всё тратит ваш лимит Claude.
4. По желанию добавьте в переменные окружения ключи `JOOBLE_API_KEY`, `FANTASTIC_JOBS_API_KEY`, `APIFY_TOKEN` (не пишите их в чат).

Работодателям ничего не отправляется автоматически: отклики вы подаёте сами.

## Структура
- `PROFILE.md`, `config.json` — профиль и настройки кандидата
- `SEARCH.md` — инструкция запуска поиска; `tools/search/` — источники, ключевые слова, правила оценки
- `tools/fetch_apis.py`, `tools/prefilter.py`, `tools/build_tracker.py` — сбор API, фильтр, сборка данных трекера
- `tools/cv/build_cv.py` — сборка CV в PDF из JSON
- `tracker/` — страница трекера и её данные
