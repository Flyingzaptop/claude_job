# Оценка вакансии: две отдельные оценки

Прочитай PROFILE.md. Для каждой вакансии строка JSON:
{"id", "fit": 0-10, "schedule": 0-10, "track": "a"|"b", "level": "intern|junior|mid+|unclear",
 "format": "onsite|hybrid|remote|unclear", "office_days": "число или пусто", "flex_hours": true|false|"unclear",
 "cv": "a"|"b", "why": "1 конкретная фраза", "red_flags": "коротко или пусто"}

**fit — навыки.** Сравни обязательные требования с подтверждённой базой из PROFILE.md.
Требуемый опыт/уровень заметно выше, чем у кандидата → ≤3. Обязательный язык, которого у кандидата нет → ≤2.
Роль не из направлений A/B → ≤1. Обязательное требование, которого нет (диплом, лицензия, разрешение) → минус 2. Не завышай.

**schedule — совместимость с «Жёсткими условиями» и «Радиусом» из PROFILE.md.**
10: условия выполнены явно. 7–8: формат подходит, но часть условий не указана. 4–6: неясно, можно согласовать.
1–3: противоречит условиям (дни в офисе, фиксированные смены, далеко). 0: несовместимо. Неизвестно → 5 и пометка в red_flags.

Пиши через Bash heredoc пачками. Не используй скрипты с оценкой по ключевым словам.
